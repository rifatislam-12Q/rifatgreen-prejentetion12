# GreenShop - আমাদের ২০২৯ সালের বাংলাদেশ 🌾🇧🇩
> **Bangladesh 64 Administrative Districts & Decentralized Agricultural Supply Chain (2029 Vision)**

গ্রিনশপ হলো একটি আধুনিক, সম্পূর্ণ রেসপনসিভ এবং ইন্টারেক্টিভ ওয়েব প্রেজেন্টেশন ও অ্যানালাইসিস প্ল্যাটফর্ম। এখানে বাংলাদেশের ৬৪টি প্রশাসনিক জেলার কৃষিজ বৈশিষ্ট্য, বিশেষায়িত ফসল (যেমন: দিনাজপুরের কাটারিভোগ/চিনিগুঁড়া চাল ও লিচু, পাবনার বোম্বাই লিচু ও দুধ, পঞ্চগড়ের গম, ভুট্টা ও অর্গানিক চা), স্থানীয় পর্যায়ে বিকেন্দ্রীকৃত প্রসেসিং মিলের বিজনেস কেস এবং বাংলাদেশের **২টি আন্তর্জাতিক গ্লোবাল হাব (ঢাকা হযরত শাহজালাল আন্তর্জাতিক বিমানবন্দর - এয়ার কার্গো হাব এবং চট্টগ্রাম সমুদ্র ও নৌবন্দর - মেরিটাইম সিপোর্ট হাব)**-এর সাথে সংযুক্ত **হাব-অ্যান্ড-স্পোক (Hub-and-Spoke)** সরবরাহ শৃঙ্খল চমৎকারভাবে উপস্থাপন করা হয়েছে।

## 📱 সর্বজনীন রেসপনসিভ ডিজাইন (Universal Responsive)
- **স্মার্টফোন (Mobile):** টাচ জেসচার, স্ক্রোল-বান্ধব ফিল্টার, অপ্টিমাইজড ভেক্টর ম্যাপ ও ফুল-স্ক্রিন বটম শীট।
- **ট্যাবলেট (Tablet):** পাশাপাশি ম্যাপ ও বিশ্লেষণ কার্ডের সুষম বিন্যাস।
- **ল্যাপটপ ও ডেস্কটপ (Desktop):** আল্ট্রা-ওয়াইড ভিউপোর্ট, জুম ও প্যান কন্ট্রোল, অ্যানিমেটেড সরবরাহ ভেক্টর ও লাইভ আরওআই (ROI) সিমুলেটর।

## 🚀 গিটহাবে আপলোড করার নিয়ম (GitHub Push Commands)

আপনার কম্পিউটারে টার্মিনাল বা VS Code ওপেন করে নিচের কমান্ডগুলো রান করুন:

```bash
# ১. গিট ইনিশিয়ালাইজ করুন
git init

# ২. সব ফাইল যুক্ত করুন
git add .

# ৩. কমিট করুন
git commit -m "First commit - GreenShop Bangladesh 2029"

# ৪. মেইন ব্রাঞ্চ সেট করুন
git branch -M main

# ৫. আপনার গিটহাব রিপোজিটরি রিমোট যুক্ত করুন
git remote add origin https://github.com/rifatislam-12Q/rifatgreen-prejentetion12.git

# ৬. গিটহাবে পুশ করুন
git push -u origin main
```

## 🌐 GitHub Pages-এ কোনো সমস্যা ছাড়া লাইভ আউটপুট পাওয়ার নিয়ম

React ও Vite প্রজেক্টে সোর্স কোড (`.tsx`) থাকে যা ব্রাউজার সরাসরি পড়তে পারে না। তাই সাধারণ ব্র্যাঞ্চ ডেপ্লয় করলে সাদা স্ক্রিন (Blank Screen) আসার ঝুঁকি থাকে। 
আপনার সুবিধার জন্য আমরা **স্বয়ংক্রিয় GitHub Actions ওয়ার্কফ্লো (`.github/workflows/deploy.yml`)** এবং `vite.config.ts`-এ **`base: './'`** কনফিগার করে দিয়েছি, যাতে কোনো লিংকিং বা পাথের সমস্যা না হয়!

### ✅ সবচেয়ে সহজ ও সেরা পদ্ধতি: GitHub Actions (১ ক্লিকে অটোমেটিক)

১. টার্মিনাল বা VS Code-এ এই প্রজেক্টের সব ফাইল গিটহাবে পুশ করুন:
```bash
git init
git add .
git commit -m "GreenShop full project with photo notes & scrollable UI"
git branch -M main
git remote add origin https://github.com/rifatislam-12Q/rifatgreen-prejentetion12.git
git push -u origin main
```

২. গিটহাবে আপনার রিপোজিটরি লিংকে যান:
👉 **[github.com/rifatislam-12Q/rifatgreen-prejentetion12](https://github.com/rifatislam-12Q/rifatgreen-prejentetion12)**

৩. উপরে থাকা **Settings** ট্যাবে যান &rarr; বামের মেনু থেকে **Pages**-এ ক্লিক করুন।

৪. **Build and deployment** সেকশনের **Source** ড্রপডাউনে:
   - **`GitHub Actions`** নির্বাচন করুন (যা আপনার স্ক্রিনশটে ইতিমধ্যেই সিলেক্ট করা আছে!)।

৫. আপনি কোড পুশ করার সাথে সাথেই রিপোজিটরিতে থাকা `.github/workflows/deploy.yml` স্বয়ংক্রিয়ভাবে প্রজেক্ট বিল্ড করে ১ মিনিটের মধ্যে লাইভ করে দেবে!
লাইভ প্রজেক্ট দেখার লিংক:
👉 **https://rifatislam-12Q.github.io/rifatgreen-prejentetion12/**

### 💡 বিকল্প পদ্ধতি: একক (Single) HTML ফাইল পদ্ধতি
যদি কোনো টার্মিনাল বা বিল্ড সেটআপ ছাড়াই সরাসরি আউটপুট দেখতে চান:
১. এই অ্যাপ্লিকেশনের উপরের ডান কোণায় থাকা **"একক HTML এক্সপোর্ট"** বাটনে চাপ দিয়ে `index.html` ডাউনলোড করুন।
২. আপনার কম্পিউটারে ফাইলটি ডাবল ক্লিক করলেই যেকোনো ব্রাউজারে অফলাইনেও চমৎকারভাবে চলবে!
৩. অথবা এই `index.html` ফাইলটি সরাসরি আপনার গিটহাব রিপোজিটরিতে রেখে Settings > Pages থেকে `Deploy from a branch` > `main` > `root` দিয়েও লাইভ করতে পারেন।

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)
1. **৬৪ জেলার ভেক্টর এসভিজি ম্যাপ:** প্রতিটি জেলা আলাদা রঙের বর্ডার, বিভাগভিত্তিক কোডিং এবং ক্লিক ইভেন্ট সংবলিত।
2. **ডাইনামিক বিজনেস কেস পপ-আপ:** কৃষিজ তথ্য, অর্থনৈতিক তাৎপর্য, অপচয় হ্রাস, মূলধন বিনিয়োগ ও লাভ্যাংশ প্রক্ষেপণ।
3. **লাইভ আরওআই (ROI) সিমুলেটর:** কৃষক জমি ও দৈনিক ধারণক্ষমতার স্লাইডার পরিবর্তন করে তাৎক্ষণিক বার্ষিক সংরক্ষিত খাদ্য ও কৃষকের বাড়তি আয় হিসাব।
4. **৮টি আঞ্চলিক করিডোর ও ঢাকা কেন্দ্রীয় টার্মিনাল:** যমুনা ও পদ্মা সেতু এক্সপ্রেসওয়ের মাধ্যমে সরাসরি খাদ্য পরিবহনের লাইভ অ্যানিমেশন।
5. **কৌশলগত প্রেজেন্টেশন স্লাইড:** স্টেকহোল্ডার ও নীতিনির্ধারকদের সামনে প্রদর্শনের জন্য রেডিমেড স্লাইড ডেক।
